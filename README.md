# Conti

PWA personale per consultare e inserire entrate e uscite. Legge e scrive sul foglio Google "Contabilita" tramite la web app Apps Script (token salvato solo sul dispositivo). Nessun dato è contenuto in questo repository.

- `index.html` – app: Home, Movimenti (filtri), Analisi (grafici), Impostazioni (tema, ricorrenze, esci); ricerca, inserimento, modifica, preferiti, stipendio, eventi, coda offline. Interfaccia ispirata al kit "Personal Finance Management App" (Figma Community)
- `sw.js` – service worker (app disponibile offline)
- `manifest.webmanifest`, `icons/` – installazione sulla schermata Home
